# Weekly SEO Plan — 2026-09-02

## Performance Summary
The Search Console export is now live, but currently only covers a single day (2026-08-30) — 48 rows total, so this week's read is a first snapshot rather than a trend. In that one day the site had ~6 clicks against roughly 186+ impressions on the homepage alone, with most queries at 0% CTR. The most useful early signal is a page/query mismatch: several pub- and cafe-related queries ("dog friendly pubs dumfries" pos 2.3, "dog cafes" pos 6.0, "cafe near me dog friendly" pos 2.0) rank reasonably well, but the site's own dedicated `/pubs-cafes/` page ranks only position 34.4 — something else (likely the homepage) is absorbing that relevance instead of the purpose-built page.

## Action Items

### 1. Rewrite title/meta on the Pubs & Cafes hub page
**Type:** improve-listing
**Why:** `/pubs-cafes/` gets 9 impressions but ranks position 34.4 for its topic, while related queries the page should own ("dog friendly pubs dumfries" pos 2.3, "dog cafes" pos 6.0, "cafe near me dog friendly" pos 2.0, "dog friendly cafe dumfries" pos 6.0) are ranking well from elsewhere on the site (most likely the homepage). The dedicated page is losing to a non-dedicated one.
**Task:** Rewrite the `<title>` and meta description on `/pubs-cafes/` to explicitly target "dog friendly pubs Dumfries and Galloway" / "dog friendly cafes near me", add an H1/intro paragraph using those exact phrases, and strengthen internal links to it from the homepage so search engines associate the page (not the homepage) with these queries.

### 2. Improve homepage title and meta description
**Type:** improve-post
**Why:** The homepage (`/`) is the single biggest impression source (186 impressions, position 6.5 — near page 1) but converts at only 2.15% CTR (4 clicks). It is ranking well enough to be seen; it isn't compelling enough to be clicked.
**Task:** Rewrite the homepage `<title>` and meta description to lead with a clear value proposition (e.g. "Dog Friendly Places in Dumfries & Galloway — Pubs, Beaches, Walks & Stays") and include a call to action, to lift CTR at the existing ranking position.

### 3. Rewrite title/meta on the interactive map page
**Type:** improve-post
**Why:** `/map/` is the second-highest impression page (38 impressions) but has 0 clicks and a weak average position (15.2). It's being shown but not clicked and not ranking strongly.
**Task:** Rewrite the `/map/` page's title and meta description to describe what the map contains (e.g. "Map of Dog Friendly Pubs, Beaches & Walks in Dumfries and Galloway") rather than a generic "Map" label, and add a short on-page intro paragraph with the same targeted phrasing to support ranking.
